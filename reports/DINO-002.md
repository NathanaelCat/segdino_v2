# DINO-002：SegDINO-v2 端到端差分微调实验

> 状态：`completed`（已完成）
> 记录更新：2026-09-04
> 相关基线：`DINO-001` (Frozen Backbone Linear Probe) 与 Constant LR 基线

## 1. 实验元数据与调度实现细节

| 字段 | 内容 |
|---|---|
| **实验编号** | `DINO-002` |
| **研究问题** | 在小样本低空遥感溢油分割（811张训练图）场景中，探索 DINOv3 视觉大模型的最优适配机制（Adaptation Regime）；测定端到端全量微调所能达到的领域自适应性能上限（Domain Adaptation Upper Bound） |
| **微调策略** | 从官方预训练权重全新冷启动（不加载任何已有 OSD 解码头权重），采用 **保持比例的差分余弦调度（Ratio-preserving Differential Cosine Schedule）** 与 3-epoch warmup |
| **调度器实现细节** | - 解码头（Decoder）：初始 LR = $1\times 10^{-4}$，退火下界 = $1\times 10^{-6}$；<br>- 骨干网（Backbone）：初始 LR = $1\times 10^{-5}$，退火下界 = $1\times 10^{-7}$；<br>- 两个参数组共享同一余弦衰减因子，全程保持骨干学习率为解码头的 0.1 倍 |
| **后期学习率状态** | 在 Epoch 38~50，Decoder LR 处于 $1.6\times 10^{-5} \to 1.0\times 10^{-6}$，Backbone LR 处于 $1.6\times 10^{-6} \to 1.0\times 10^{-7}$；骨干更新步长在后期已被大幅压缩，这是后期曲线极度平滑的重要成因之一 |
| **对照基线** | `DINO-001` (Frozen DINOv3-S, Decoder 1e-4, Val Best 90.63%, Test 89.95%) 与 Constant Baseline (Val Best 92.70%, Test 90.96%) |
| **协议标准** | `OSD-EXP-v1.0/L4-global-512`；train/val/test=811/203/254；主指标 `mIoU3_report_only_global` |
| **配置文件** | `segdino_v2/configs/osd_v2_512_finetune.json` |
| **随机种子** | `20260901` |
| **训练耗时** | 50 Epochs / 5100 Steps；总耗时 1768.78 s (29.48 min)；峰值显存 18,305 MiB (~18.3 GB) |
| **环境硬件** | Linux `vp-166`；NVIDIA GeForce RTX 4090 GPU1；Conda `segdino_osd` |

## 3. 科学结论与论文定位

1. **确定性泛化增益（Demonstrated Generalization Gain）**：
   - 解冻骨干网络进行差分微调，使测试集泛化指标从冻结机制的最佳值（90.96%）跃升至 **93.46%**（净增长 **+2.50 pp**），证明了端到端领域自适应在跨模态遥感溢油特征提取中的必要性；
   - 核心难点类别**溢油（Oil）**达到 **93.33%**（提升 +4.15 pp），**水体（Water）**达到 **90.40%**（提升 +3.43 pp），显著改善了边界模糊区域的错分现象。
2. **论文评测体系定位（Dual-table Evaluation Framework）**：
   - **精度主表（Accuracy Table）**：DINO-002 全量微调作为当前最强性能上限呈现；
   - **精度—效率消融表（Accuracy-Efficiency Table）**：将 DINO-001/003 冻结骨干（仅 3.3M 可调参数、节省 85% 训练开销即可达 90.4%~91.0%）作为轻量高效迁移方案进行对齐分析；
   - 进而探索未来在小样本遥感场景下的第三条路线：参数高效微调（PEFT / LoRA / Adapter）。
