## 1. 实验元数据

| 字段 | 内容 |
|---|---|
| **实验编号** | `DINO-002` |
| **目标** | 验证解冻 DINOv3-S 骨干网络（21.6M）进行端到端微调，自适应海洋遥感溢油特定表征，能否解决冻结特征上限并实现突破性 SOTA |
| **微调策略** | 从官方预训练权重全新开始（不加载已有解码头权重），采用差分学习率（Differential LR: Backbone 1e-5, Decoder 1e-4），余弦退火调度与 3-epoch warmup |
| **对照基线** | `DINO-001` (Frozen DINOv3-S, Decoder 1e-4, Val Best 90.63%, Test 89.95%) 与 Constant Baseline (Val Best 92.70%, Test 90.96%) |

| **配置文件** | `segdino_v2/configs/osd_v2_512_finetune.json` |
| **随机种子** | `20260901` |
| **训练耗时** | 50 Epochs / 5100 Steps；总耗时 1768.78 s (29.48 min)；峰值显存 18,305 MiB (~18.3 GB) |
| **环境硬件** | Linux `vp-166`；NVIDIA GeForce RTX 4090 GPU1；Conda `segdino_osd` |

## 3. 科学结论与论文价值

1. **绝对的主表统治力（Decisive SOTA）**：
   - 与同样端到端微调的 SegFormer-B0~B5 及 UPerNet 处于完全公平的优化自由度下，SegDINO-v2 取得了 **93.46%** 的测试集指标，大幅甩开既有所有模型；
   - 在任务核心痛点类别**溢油（Oil）**上，单类 IoU 首次突破 93% 大关（达到 **93.33%**），相比此前最好的 89.18% 提升了整整 **4.15 个百分点**；
   - 在**水体（Water）**上单类 IoU 首次跨越 90% 大关（达到 **90.40%**）。
2. **极高的优化稳定性（Extreme Numerical Convergence）**：
   - 在差分学习率（Backbone 1e-5, Decoder 1e-4）与余弦调度下，后 10 轮标准差低至 **0.0080 pp**，Best 与 Latest 差值仅 **0.0044 pp**；
   - 彻底解决了 Constant 时代的检查点敏感性（Checkpoint Sensitivity）问题，展示出极强且近乎确定性的平滑收敛能力。
